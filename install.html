Download PyMOL-Open-Source

Current version: 3.2.0.3+1 (the application shows the version of its PyMOL core, e.g. 3.2.0a)

Windows

Requires Windows 10 (version 22H2) or Windows 11, 64-bit.

  • Installer: PyMOL-Open-Source_v3.2.0.3+1_x64_setup.exe
  • Portable (no installation, extract and run): PyMOL-Open-Source_v3.2.0.3+1_x64_portable.zip

To access a step-by-step installation guide, click here.

macOS

Requires macOS 12 (Monterey) or newer.

  • Apple Silicon (M1, M2, M3, ...): PyMOL-Open-Source_v3.2.0.3+1_macOS_AppleSilicon.dmg
  • Intel: PyMOL-Open-Source_v3.2.0.3+1_macOS_Intel.dmg

Not sure which Mac you have? Open the Apple menu and choose About This Mac: "Chip: Apple M..." means Apple Silicon, "Processor: ... Intel ..." means Intel.

To access a step-by-step guide, click here.

Linux

Requires a 64-bit (x86_64) distribution. Tested on Ubuntu 22.04 and 24.04, Debian 12, Fedora, Rocky Linux 9, AlmaLinux 8, openSUSE Leap 15.6 and Tumbleweed.

  • Debian, Ubuntu (.deb): PyMOL-Open-Source_v3.2.0.3+1_amd64.deb
  • Fedora, RHEL, openSUSE (.rpm): PyMOL-Open-Source_v3.2.0.3+1_x86_64.rpm
  • Portable (.tar.gz): PyMOL-Open-Source_v3.2.0.3+1.tar.gz

To access an installation guide, click here.

All versions are available on the releases page.
